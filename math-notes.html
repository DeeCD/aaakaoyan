01

函数、极限与连续

极限是微积分的基石：所有导数、积分、级数都建立在极限之上。

函数基础

  • 基本初等函数：幂、指数、对数、三角、反三角、常数函数
  • 复合函数、反函数、隐函数、参数方程表示
  • 函数特性：奇偶性、周期性、单调性、有界性
  • 反函数性质：单调函数必有反函数，图像关于 y=x 对称

极限定义与性质

  • ε-δ 定义、ε-N 定义（数列极限）
  • 唯一性、有界性、保号性、四则运算法则
  • 夹逼准则、单调有界准则（数列极限存在）
  • 无穷小/无穷大：高阶、同阶、等价无穷小替换
  • 常用等价：x→0 时 sinx~x、tanx~x、ln(1+x)~x、e^x−1~x、1−cosx~x²/2

两个重要极限

  • 第一重要极限：lim sinx/x = 1（x→0）
  • 第二重要极限：lim (1+1/x)^x = e（x→∞）；lim (1+x)^(1/x) = e（x→0）
  • 推广形式：lim (1+f(x))^(1/f(x)) = e（f(x)→0）

连续与间断

  • 连续定义：lim f(x) = f(x₀)（x→x₀）
  • 间断点分类：第一类（可去/跳跃）、第二类（无穷/振荡）
  • 闭区间连续函数性质：最值定理、介值定理、零点定理
记忆点：等价无穷小替换只能在乘除因子中使用；0/0 型极限优先考虑「等价替换 + 洛必达 + 泰勒」三板斧。
考研真题本章典型真题与解析

【计算题】求 lim(x→0) sinx / x 的值。

答案：1。这是第一重要极限，也可由 sinx~x（x→0）等价替换直接得出。

【计算题】求 lim(x→∞) (1 + 1/x)^x 的值。

答案：e。第二重要极限，底数趋于 1 且指数趋于无穷，标准形式 (1+1/x)^x → e。

【选择题】当 x→0 时，下列与 x 是等价无穷小的是？A. sinx B. 1−cosx C. x² D. e^x

答案：A。sinx~x；1−cosx~x²/2（x 的二阶无穷小）；x² 是二阶；e^x 的等价无穷小是 e^x−1~x，e^x 本身趋于 1。

02

一元函数微分学

导数刻画变化率，微分作线性近似；中值定理连接导数与函数形态。

导数与微分

  • 导数定义：f'(x₀) = lim [f(x₀+h)−f(x₀)]/h（h→0）
  • 基本公式：(x^n)'=nx^(n−1)、(lnx)'=1/x、(e^x)'=e^x、(sinx)'=cosx
  • 四则与复合：乘积法则、链式法则（内导乘外导）
  • 隐函数求导、参数方程求导、对数求导法
  • 微分：dy = f'(x)dx，可微⇔可导

中值定理

  • 罗尔定理：端点值相等⇒存在 f'(ξ)=0
  • 拉格朗日中值定理：f(b)−f(a)=f'(ξ)(b−a)
  • 柯西中值定理：两个函数比值的推广形式
  • 泰勒公式：f(x) 在 x₀ 处的多项式展开 + 余项（佩亚诺/拉格朗日余项）
  • 洛必达法则：0/0、∞/∞ 型极限可对分子分母分别求导

导数应用

  • 单调性：f'(x)>0 单调递增，f'(x)<0 单调递减
  • 极值判定：f'(x₀)=0 且 f''(x₀)<0 取极大；f''(x₀)>0 取极小
  • 凹凸性：f''(x)>0 凹（下凸），f''(x)<0 凸；拐点处 f'' 变号
  • 渐近线：水平、垂直、斜渐近线判定
  • 曲率：K=|y''|/(1+y'²)^(3/2)

高阶导数与常见展开

  • e^x = Σ x^n/n!（n=0→∞），sinx、cosx 交错展开
  • ln(1+x) = x − x²/2 + x³/3 − …
  • (1+x)^α 二项式展开（α 任意实数）
  • 莱布尼茨公式求高阶导数：(uv)^(n) 组合形式
记忆点：证明题三件套——构造辅助函数用罗尔/拉格朗日；求极限优先洛必达前先看能否等价替换。
考研真题本章典型真题与解析

【计算题】设 y = x²·sinx，求 y'。

答案：y' = 2x·sinx + x²·cosx。乘积法则：(uv)' = u'v + uv'。

【计算题】设函数 f(x) 在 x₀ 处满足 f'(x₀)=0 且 f''(x₀)>0，则 f(x₀) 是极大值还是极小值？

答案：极小值。f''(x₀)>0 表示二阶导为正、曲线在该点附近下凸，一阶导从负变正，故为极小值。

【证明题】写出拉格朗日中值定理的内容。

答案：若 f 在 [a,b] 连续、在 (a,b) 可导，则存在 ξ∈(a,b) 使 f(b)−f(a) = f'(ξ)(b−a)。

03

一元函数积分学

不定积分是微分的逆运算，定积分是和的极限（曲边梯形面积）。

不定积分

  • 基本公式：∫x^n dx = x^(n+1)/(n+1)+C、∫1/x dx = ln|x|+C、∫e^x dx = e^x+C
  • ∫sinx dx = −cosx+C、∫cosx dx = sinx+C、∫1/(1+x²) dx = arctanx+C
  • 换元法：第一类（凑微分）、第二类（三角/根式代换）
  • 分部积分：∫u dv = uv − ∫v du，反对幂指三顺序
  • 有理函数：部分分式分解后积分

定积分

  • 定义：∫ₐᵇ f(x)dx = lim Σ f(ξᵢ)Δxᵢ（黎曼和）
  • 牛顿-莱布尼茨公式：∫ₐᵇ f(x)dx = F(b)−F(a)
  • 换元需变限，分部积分处理乘积型
  • 奇偶性：奇函数对称区间积分为 0，偶函数为 2 倍半区间
  • 周期函数积分：周期内积分与起点无关

反常积分与几何应用

  • 无穷限反常积分：∫ₐ^∞，收敛判定（p-积分、比较判别法）
  • 无界函数反常积分（瑕积分）
  • 平面图形面积：∫|f−g| dx
  • 旋转体体积：绕 x 轴 V=π∫y²dx、绕 y 轴壳层法 V=2π∫xy dx
  • 弧长：s = ∫√(1+y'²) dx

变上限积分

  • Φ(x)=∫ₐˣ f(t)dt，则 Φ'(x)=f(x)（微积分基本定理）
  • 变上限积分求导：被积函数含 x 时需拆项或换元
  • 常用于求 0/0 型极限（结合洛必达）
记忆点：分部积分「反对幂指三」——反三角函数、对数、幂、指数、三角函数，谁先当 u 按此顺序。
考研真题本章典型真题与解析

【计算题】求 ∫₀¹ x dx 的值。

答案：1/2。∫₀¹ x dx = x²/2 |₀¹ = 1/2；几何意义为直角三角形面积。

【计算题】设 F(x)=∫₀ˣ t² dt，求 F'(x)。

答案：F'(x)=x²。变上限积分求导等于被积函数在上限处的值。

【概念题】奇函数 f(x) 在对称区间 [−a,a] 上的定积分等于多少？

答案：0。奇函数图像关于原点对称，正负面积抵消，∫₋ₐᵃ f(x)dx = 0。

04

多元函数微分学

偏导数是固定其他变量求导；全微分是多元线性近似。

偏导数与全微分

  • 偏导数：∂z/∂x 固定 y 对 x 求导；∂z/∂y 固定 x 对 y 求导
  • 高阶偏导：混合偏导 ∂²z/∂x∂y（连续条件下与顺序无关）
  • 全微分：dz = (∂z/∂x)dx + (∂z/∂y)dy
  • 可微⇒连续且偏导存在；偏导存在不一定可微
  • 复合函数链式法则、隐函数求导公式

方向导数与梯度

  • 方向导数：D_u f = ∂f/∂x·cosα + ∂f/∂y·cosβ
  • 梯度 grad f = (∂f/∂x, ∂f/∂y)
  • 梯度方向是函数增长最快的方向，模为最大方向导数
  • 等值线的法线方向即梯度方向

极值与条件极值

  • 无条件极值必要条件：偏导均为 0（驻点）
  • 判别法：AC−B² 判别（A=f_xx, B=f_xy, C=f_yy）
  • 拉格朗日乘数法：约束 g(x,y)=0 下求极值，构造 F=f+λg
  • 应用题：最大最小体积、面积、利润
记忆点：AC−B²>0 且 A>0 极小、A<0 极大；AC−B²<0 非极值；=0 需另判。
考研真题本章典型真题与解析

【计算题】设 z = x²y，求 ∂z/∂x 与 ∂z/∂y。

答案：∂z/∂x = 2xy，∂z/∂y = x²。求 ∂z/∂x 时把 y 当常数；求 ∂z/∂y 时把 x 当常数。

【概念题】函数 z=f(x,y) 在点 (x₀,y₀) 处的全微分 dz 的表达式是什么？

答案：dz = f_x(x₀,y₀)dx + f_y(x₀,y₀)dy。其中 f_x、f_y 为该点偏导数。

【选择题】梯度向量指向函数值什么方向？

答案：增长最快的方向。梯度 grad f 的方向是函数在该点上升最快的方向，其模等于最大方向导数。

05

多元函数积分学

二重积分、曲线/曲面积分，以及格林、高斯、斯托克斯三大公式。

二重积分

  • 定义：曲顶柱体体积，化累次积分（X 型/ Y 型）
  • 极坐标：x=rcosθ, y=rsinθ，dσ = r dr dθ
  • 对称性：关于 x/y 轴对称、奇偶函数简化
  • 应用：平面区域面积、薄板质量/质心

曲线积分

  • 第一类（对弧长）：∫_L f ds，与方向无关
  • 第二类（对坐标）：∫_L P dx + Q dy，与方向有关
  • 格林公式：平面闭曲线积分 ⇔ 二重积分（∂Q/∂x − ∂P/∂y）
  • 积分与路径无关：∂P/∂y = ∂Q/∂x，此时存在势函数

曲面积分与三大公式

  • 第一类曲面积分：∫∫_Σ f dS（与侧无关）
  • 第二类曲面积分：∫∫_Σ P dydz + Q dzdx + R dxdy（有向）
  • 高斯公式：闭曲面通量 ⇔ 三重积分散度
  • 斯托克斯公式：空间曲线环流 ⇔ 曲面积分旋度
  • 三重积分：直角/柱面/球面坐标
记忆点：格林管平面、高斯管闭合曲面、斯托克斯管空间曲线——三大公式本质是「边界积分 ⇔ 内部积分」。
考研真题本章典型真题与解析

【计算题】计算二重积分 ∬_D 1 dσ，其中 D 为矩形 [0,1]×[0,1]。

答案：1。∬_D 1 dσ = ∫₀¹∫₀¹ dx dy = 1，即区域面积。

【概念题】格林公式沟通了哪两类积分？

答案：平面闭曲线上的第二类曲线积分与闭曲线所围区域上的二重积分：∮_L Pdx+Qdy = ∬_D (∂Q/∂x−∂P/∂y)dσ。

【概念题】高斯公式的物理意义是什么？

答案：闭曲面上的通量等于其内部区域的散度体积分（三重积分）：∯_Σ P dydz+Q dzdx+R dxdy = ∭_V (∂P/∂x+∂Q/∂y+∂R/∂z)dV。

06

无穷级数

数项级数判敛散，幂级数求和与展开，傅里叶级数处理周期函数。

数项级数敛散性

  • 几何级数 Σqⁿ：|q|<1 收敛，|q|≥1 发散
  • p-级数 Σ1/nᵖ：p>1 收敛，p≤1 发散
  • 正项级数：比较、比值、根值判别法
  • 交错级数：莱布尼茨判别法（单调递减趋于 0 则收敛）
  • 绝对收敛 ⇔ 原级数与绝对值级数均收敛；条件收敛：原收敛绝对值发散

幂级数

  • 收敛半径：R = 1/limsup ⁿ√|aₙ| 或比值法
  • 收敛域：端点 x=±R 需单独判定
  • 和函数：逐项求导/积分，先求和再处理系数
  • 常用展开：e^x、sinx、cosx、ln(1+x)、1/(1−x)=Σxⁿ（|x|<1）
  • 泰勒展开与麦克劳林展开的关系

傅里叶级数

  • 周期函数展开：f(x) ~ a₀/2 + Σ(aₙcos nx + bₙsin nx)
  • 系数公式：aₙ、bₙ 由定积分计算
  • 奇函数只有正弦项，偶函数只有余弦项（含 a₀）
  • 收敛定理：连续点收敛于 f(x)，间断点收敛于左右极限平均
记忆点：判敛顺序：先看通项是否趋于 0（不趋于必发散）→ 正项用比值/根值/比较 → 交错用莱布尼茨。
考研真题本章典型真题与解析

【计算题】判断级数 Σ(1/2)ⁿ（n=1→∞）是否收敛，若收敛求其和。

答案：收敛，和为 1。几何级数公比 q=1/2，|q|<1 收敛，和 = a/(1−q) = (1/2)/(1−1/2) = 1。

【判断题】p-级数 Σ1/nᵖ 在什么条件下收敛？

答案：p>1 收敛。p>1 收敛；p=1 为调和级数发散；p<1 发散。

【概念题】交错级数 Σ(−1)ⁿ⁺¹ aₙ（aₙ>0）满足什么条件时收敛？

答案：莱布尼茨判别法：aₙ 单调递减且趋于 0，则交错级数收敛。

07

常微分方程

解方程的核心是识别类型：可分离、一阶线性、二阶常系数、欧拉方程。

一阶方程

  • 可分离变量：dy/dx = f(x)g(y)，两边分别积分
  • 齐次方程：dy/dx = φ(y/x)，令 u=y/x 代换
  • 一阶线性：y'+P(x)y = Q(x)，通解 y = e^{−∫P dx}[∫Q e^{∫P dx} dx + C]
  • 伯努利方程：y'+P y = Q yⁿ，令 z=y^(1−n) 化线性
  • 全微分方程：∂P/∂y=∂Q/∂x 时求原函数

二阶常系数线性方程

  • 齐次：y''+py'+qy=0，特征方程 r²+pr+q=0
  • 两不等实根 r₁≠r₂：y=C₁e^{r₁x}+C₂e^{r₂x}
  • 重根 r：y=(C₁+C₂x)e^{rx}
  • 共轭复根 α±βi：y=e^{αx}(C₁cosβx+C₂sinβx)
  • 非齐次：通解 = 齐次通解 + 特解（待定系数法/常数变易法）

高阶与特殊方程

  • 可降阶：缺 y 型 y''=f(x,y')（令 p=y'）；缺 x 型
  • 欧拉方程：x²y''+pxy'+qy=0，令 x=e^t 化常系数
  • 应用：弹簧振动（自由/强迫）、RC 电路、人口模型
记忆点：二阶常系数齐次通解三情形，完全由特征方程判别式决定：Δ>0 两实根、Δ=0 重根、Δ<0 复根。
考研真题本章典型真题与解析

【计算题】求微分方程 y'' + y = 0 的通解。

答案：y = C₁cosx + C₂sinx。特征方程 r²+1=0，特征根 r=±i（α=0, β=1），故通解为 C₁cosx+C₂sinx。

【计算题】求一阶线性方程 y' + y = 0 的通解。

答案：y = Ce^(−x)。可分离变量：dy/y = −dx，两边积分得 ln|y| = −x + C。

【概念题】特征方程 r² − 3r + 2 = 0 对应齐次方程的通解形式？

答案：y = C₁e^x + C₂e^(2x)。特征根 r=1,2 为两不等实根，通解按 e^{r₁x}、e^{r₂x} 组合。

08

线性代数

行列式、矩阵、向量组、线性方程组、特征值与二次型——五章一线牵。

行列式与矩阵

  • 2 阶行列式：|a b; c d| = ad − bc；按行/列展开（代数余子式）
  • 矩阵运算：加法、数乘、乘法（不满足交换律）、转置
  • 逆矩阵：AA⁻¹=E；A⁻¹ = A*/|A|（伴随矩阵）
  • 初等变换与初等矩阵；矩阵的秩 r(A)
  • 分块矩阵运算

向量组与方程组

  • 线性相关/无关：存在不全为零系数使组合为零向量则相关
  • 秩：极大无关组中向量个数；r(A)=列向量组秩=行向量组秩
  • 方程组 Ax=b 有解 ⇔ r(A)=r(A|b)；唯一解 ⇔ r(A)=n
  • 齐次 Ax=0 基础解系：解空间维数 = n − r(A)
  • 克拉默法则：|A|≠0 时唯一解

特征值与二次型

  • 特征方程：|λE − A| = 0；特征向量满足 Aα = λα
  • 性质：特征值之和 = 迹 tr(A)，之积 = |A|
  • 相似对角化：A 可对角化 ⇔ 有 n 个线性无关特征向量
  • 实对称矩阵：必可正交对角化，不同特征值特征向量正交
  • 二次型 xᵀAx：标准形（配方法/正交变换）、正定判定（顺序主子式>0）
记忆点：λ 的三大线索：对角线之和（迹）、行列式、|λE−A|=0；实对称矩阵是考研线代的高频主角。
考研真题本章典型真题与解析

【计算题】计算行列式 |3 1; 2 4|。

答案：10。3×4 − 1×2 = 12 − 2 = 10。

【计算题】矩阵 A = [[2,0],[0,3]] 的特征值是多少？

答案：λ₁=2，λ₂=3。对角矩阵的特征值即主对角线元素；也可由 |λE−A|=(λ−2)(λ−3)=0 得出。

【概念题】n 元齐次线性方程组 Ax=0 有非零解的充要条件是什么？

答案：r(A) < n。系数矩阵的秩小于未知量个数时，基础解系含 n−r(A) 个解向量，必有非零解。

概率论与数理统计

随机事件的概率、随机变量的分布、数字特征、大数定律与统计推断。

随机事件与概率

  • 古典概型：P(A)=有利/总；几何概型
  • 条件概率：P(A|B)=P(AB)/P(B)
  • 全概率公式：P(A)=ΣP(Bᵢ)P(A|Bᵢ)
  • 贝叶斯公式：P(Bᵢ|A)=P(Bᵢ)P(A|Bᵢ)/P(A)
  • 事件独立：P(AB)=P(A)P(B)

随机变量及其分布

  • 离散型：0-1 分布、二项 B(n,p)、泊松 P(λ)、几何分布
  • 连续型：均匀 U(a,b)、指数 Exp(λ)、正态 N(μ,σ²)
  • 分布函数 F(x)=P(X≤x)，密度 f(x)=F'(x)
  • 标准化：Z=(X−μ)/σ ~ N(0,1)
  • 二维随机变量：联合分布、边缘分布、条件分布、独立性

数字特征与大数定律

  • 期望 E(X)=Σxᵢpᵢ（离散）/ ∫xf(x)dx（连续）
  • 性质：E(aX+b)=aE(X)+b；E(X+Y)=E(X)+E(Y)
  • 方差 D(X)=E(X²)−[E(X)]²；D(aX+b)=a²D(X)
  • 协方差与相关系数 ρ=Cov(X,Y)/√(DXDY)
  • 大数定律：样本均值依概率收敛于期望；中心极限定理：大量独立同分布变量和近似正态

数理统计

  • 总体、样本、统计量：样本均值 X̄、样本方差 S²
  • χ²、t、F 三大分布及抽样分布定理
  • 参数估计：矩估计、最大似然估计（无偏性、有效性）
  • 假设检验：显著性水平 α、拒绝域、两类错误
  • 置信区间：正态总体均值的区间估计
记忆点：贝叶斯 = 先验 × 似然 / 全概率分母；正态标准化 Z=(X−μ)/σ 是几乎所有正态计算的入口。
考研真题本章典型真题与解析

【计算题】设随机变量 X~N(0,1)，写出其标准化形式及密度函数形式要点。

答案：标准正态 N(0,1) 密度 f(x)=(1/√(2π))e^(−x²/2)；一般 X~N(μ,σ²) 通过 Z=(X−μ)/σ 化为标准正态。

【计算题】设 E(X)=2，D(X)=3，求 E(3X+1) 与 D(3X+1)。

答案：E=7，D=27。E(3X+1)=3×2+1=7；D(3X+1)=3²×3=27（方差平移不变、缩放取平方）。

【概念题】写出全概率公式。

答案：若 B₁,…,Bₙ 构成完备事件组（互斥且并集为全空间），则 P(A)=ΣP(Bᵢ)P(A|Bᵢ)。
